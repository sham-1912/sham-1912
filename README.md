### About me

I'm a developer who learns by shipping. Most of what I've built started as a hackathon or competition entry, from an Android app that fights call-spoofing fraud to a cross-chain protocol and a trading agent.

- **Now:** building an LLM project (repo coming soon)
- **Recently:** [Vayusight](https://github.com/sham-1912/Vayusight), an explainable air-quality forecasting pipeline
- **Hackathons:** InnovaHack, CSI Origins, and the builderr trading-agent competition
- **I work with:** Python, TypeScript/React, Kotlin and Solidity
- **Ask me about:** data pipelines, building under a deadline, and getting a first version out the door

### Featured projects

| Project | What it does | Stack |
| --- | --- | --- |
| [**Vayusight**](https://github.com/sham-1912/Vayusight) | Multi-source AQI forecasting and spatial estimation with a hyperlocal health-risk layer and an explainable-ML dashboard. | Python, Pydantic, Plotly Dash, SHAP, Google Earth Engine |
| [**Compliance Forensics Engine**](https://github.com/sham-1912/cfe-ComplianceEngine) | InnovaHack Android app (built with Team Novaris in 24 hours) that checks on-device whether an incoming caller is authorised under India's TRAI framework, to help stop spoofing and financial fraud. | Kotlin, Room, Firebase, Retrofit |
| [**Zyntek**](https://github.com/sham-1912/Zyntek) | CSI Origins hackathon entry: a decentralized intent-solver network for cross-chain transfers. Solvers compete, post collateral, and are paid only after verified delivery. | React 19, TypeScript, Vite, Tailwind, Solidity, Hardhat |
| [**builderr-trading-agent**](https://github.com/sham-1912/builderr-trading-agent) | My entry to a daily-bar paper-trading competition: a rule-based regime-switching strategy ranked by Calmar ratio. | Python |
